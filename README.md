# Fröccs mobiljáték – nem hivatalos prototípus

Flutter-alapú, közösségi digitális prototípus Hajnóczy Soma Fröccs társasjátéka nyomán. Az eredeti grafikai elemek és teljes kártyaszövegek nem részei a repónak; publikálás előtt a szerző és a kiadó engedélye szükséges.

A játék és telepítés dokumentációja a fejlesztéssel együtt bővül.
