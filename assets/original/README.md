# Eredeti Fröccs grafikai assetek

Hajnóczy Soma engedélyével itt használhatók az eredeti grafikai állományok.
A hivatalos exportfájlok még nem állnak rendelkezésre ebben a repóban.
Ne dolgozzunk rossz minőségű webshop-képekkel kártyaképként.

A tényleges kártyaképeket a forrásfájlok beérkezése után kell bekötni.
A jelenlegi UI szöveges és szimbólumos helyettesítőket használ.
A grafikai engedély terjedelmét, a kiadói és illusztrátori jogokat
a nyilvános megjelenés előtt írásban érdemes dokumentálni.
